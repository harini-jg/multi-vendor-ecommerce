
# Multi-Vendor E-Commerce Marketplace

An Amazon-style multi-vendor e-commerce marketplace that allows customers to browse products, add items to a cart, and place orders. Vendors can manage their products through a dedicated dashboard.

## Live Demo

- Frontend: https://multi-vendor-ecommerce-green.vercel.app
- Backend: https://multi-vendor-ecommerce-production-92e9.up.railway.app
- GitHub: https://github.com/harini-jg/multi-vendor-ecommerce.git

## Features

### Customer
- User Signup and Login
- Browse Products
- Product Images and Details
- Add Products to Cart
- Place Orders
- View My Orders

### Vendor
- Vendor Dashboard
- Add Products
- Edit Products
- Delete Products
- Manage Product Stock

## Technologies Used

### Frontend
- React.js
- Vite
- JavaScript
- CSS
- Axios
- React Router

### Backend
- Java
- Spring Boot
- Spring Security
- JWT Authentication
- REST API

### Database
- MySQL

### Deployment
- Frontend: Vercel
- Backend: Railway

## Project Objective

To develop a secure and user-friendly multi-vendor e-commerce platform where multiple vendors can manage their products and customers can purchase products online.

## Security Features

- JWT-based authentication
- BCrypt password encryption
- Spring Security
- CORS configuration
